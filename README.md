# mtm6201_final
I developed this website using HTML, CSS, and Bootstrap, aiming to create a responsive and user-friendly experience across various devices. The structure is built around key sections, including a navigation bar, main content area with image banners, and a card layout for displaying important information such as donation details. I utilized Bootstrap's grid system to organize content and ensure the layout adjusts fluidly across different screen sizes. Custom CSS was applied to refine the design, including font styling, button designs, and spacing. Additionally, I incorporated media queries to optimize the website’s appearance for mobile, tablet, and desktop views. Interactive elements like buttons and links were added to encourage user engagement, and accessibility standards were followed to ensure a smooth browsing experience. The use of images, icons, and text overlays further enhances the visual appeal, while the overall layout is intended to be clean, informative, and easy to navigate.
