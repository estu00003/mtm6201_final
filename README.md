# mtm6201_final
This website was developed as an extension of my UX project focused on improving animal adoption experiences through an accessible and visually engaging online platform. Starting with a detailed mockup created during my UX course, I designed the layout and features with the user in mind—specifically potential adopters, donors, and volunteers. The intention behind this project was to create a welcoming space where stray and sheltered animals could be given better chances of finding loving homes.

I used HTML, CSS, and Bootstrap to bring the design to life, incorporating a responsive navigation bar, image banners, sub-navigation, and informative card sections. Each element was structured using Bootstrap’s grid system and enhanced with custom CSS to match the aesthetic and emotional tone set by the original UX wireframes. Media queries were applied to ensure the layout adapts smoothly to mobile, tablet, and desktop screens. Interactive components such as call-to-action buttons and highlighted sections were included to guide users towards learning more, adopting, or contributing support.

The design choices—from warm colors and friendly fonts to image-based storytelling—were made intentionally to foster empathy and action. Overall, this site reflects both my skills as an Interactive Media Design student and my hope to help stray animals find a brighter future through accessible digital design.
